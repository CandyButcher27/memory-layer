metadata:
  node_type: memory
  type: project
  originSessionId: c6405e22-c8d3-4449-a2c3-d80efd1dc696
  modified: 2026-10-04T08:33:27.967Z
---

WAL mode is intentionally turned off on the ingest database. The file lives on EFS (a network filesystem), and WAL doesn't work there.

**Why:** WAL relies on shared memory and file locking that network filesystems don't support reliably.

**How to apply:** Don't suggest or add `enable_wal()` / `journal_mode=WAL` for the ingest database, and don't flag its absence as a bug. The ingest box also runs Python 3.10, so avoid newer syntax. See [[since-option-plan]].
