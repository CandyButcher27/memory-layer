## DEC-1 — Rejected write PRAGMAs in db.query() still take effect; documented, not fixed
Why: some PRAGMAs refuse to run inside a transaction, so they run outside the savepoint guard; `PRAGMA user_version = 5` takes effect despite the ValueError (6693491)
Rejected: fixing it — needs a hardcoded list of row-returning PRAGMAs
Reverse if: a reliable way to tell row-returning PRAGMAs apart without a hardcoded list
Date: 2026-07-06

## DEC-2 — Database context manager rolls back on exit instead of committing
Why: exit equals close(); an open transaction can only come from manual transaction control, and auto-committing could silently persist half-finished work. Deliberately differs from sqlite3.Connection's context manager (6c88067)
Rejected: commit on exit like sqlite3.Connection — persists half-finished work
Reverse if: none recorded
Date: 2026-07-04

## DEC-3 — WAL mode is off on the ingest database
Why: the database file lives on EFS and WAL does not work on a network filesystem. Stated by the user 2026-10-04; deliberate, not an oversight
Rejected: enabling WAL (e.g. via enable_wal()) on the ingest database — unsupported on EFS
Reverse if: the ingest database moves off a network filesystem
Date: 2026-10-04

## DEC-4 — `rows --since` accepts ISO 8601 dates and datetimes only, parsed with the standard library
Why: decided in review 2026-10-04. Marta vetoed python-dateutil for this

# External systems

Last verified: 2026-10-04

## Release publishes to PyPI from a GitHub release
Creating a GitHub release runs .github/workflows/publish.yml: tests on all Python versions/OSes, then `twine upload` with the PYPI_TOKEN secret (docs/contributing.rst).

## Package works in tests but crashes for users (missing runtime dependency)
CI installs `--group dev`, which hides imports of dev-only packages. 4.2 shipped broken this way (ISS-1, #842). Smoke test: `uv run --isolated --no-default-groups sqlite-utils --help` (Justfile `test-no-dev-dependencies`).

## cog breaks with older click in dev dependencies
Dev group pins click>=8.4.2 to fix Cog (79117b9, issue #761).

## Ingest database on EFS (WAL off, Python 3.10)
The ingest database file lives on EFS, so WAL is deliberately disabled (DEC-3). The ingest box runs Python 3.10. The 3.11 upgrade was rolled back because a C extension the ingest box depends on does not build on 3.11 yet; it stays on 3.10 until that is fixed, so code must use nothing newer than 3.10 syntax. Stated by the user 2026-10-04, not checked against the box.

The dedupe job processes 340k rows/minute on the m6i.large (user-measured Friday 2026-10-02, 5 runs).

## Vendor CSV feed (semicolon-delimited) ends with the contract
The 40 vendor CSVs are semicolon-delimited. Tomás owns the vendor relationship. The contract ends 2027-03-31 and the feed stops then. Stated by the user 2026-10-04, not checked elsewhere.

## Nightly batch runs at 02:30 UTC
The nightly batch moved from 01:00 to 02:30 UTC after the DST switch. Stated by the user 2026-10-04, not checked against the scheduler.

## Ingest database backups (S3, hourly, 14-day retention)
The ingest database is backed up hourly to s3://acme-ingest-backups with 14-day retention. Stated by the user 2026-10-04, not checked against the bucket or the job. WAL is off (DEC-3), so a plain file copy of the live database is not safe; sqlite-utils has no backup command, but `sqlite-utils query DB "VACUUM INTO 'copy.db'"` gives a consistent copy (run 2026-10-04 on a scratch db, needs SQLite 3.27+).

# Old SQLite versions

Last verified: 2026-07-06

CI tests against SQLite 3.23.1 (2018-04-10, before UPSERT) and 3.46 in .github/workflows/test-sqlite-support.yml. Features newer than 3.23.1 must be guarded or skipped in tests.

## Test fails on SQLite 3.23.1 with a leading UTF-8 BOM
3.23.1 rejects a BOM before the first token; the BOM variant of the execute()-prefixed-BEGIN test skips there (c2a1774).

## Selecting rowid from a view returns NULL instead of erroring
Before 3.36, `rowid` from a view returned NULL rather than raising; the pks_and_rows_where() view test accepts both (c2a1774).

## INSERT ... RETURNING is a syntax error before SQLite 3.35
Tests using RETURNING are skipped on older SQLite (2582446).

## sqlite_schema not found on older SQLite
Use `sqlite_master`, not `sqlite_schema`, for older SQLite compatibility (b432e68).
